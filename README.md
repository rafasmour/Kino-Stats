## Introduction
This project aims to provide statistical analysis and insights for the Kino OPAP game, a popular lottery game in Greece. By leveraging historical data, it offers tools for analyzing patterns, trends, and probabilities.  
Since Kino is an RNG-based system, past results do **not** guarantee future outcomes.

## Features
- **Data Analysis**: Explore historical data to identify patterns and trends
- **API Endpoints**: Access data through RESTful API endpoints for integration with other applications
- **Excel Export**: Analyzed data is saved to an Excel file

## Usage
This project is useful for anyone who wants insights into past patterns and an overall overview of game statistics.

The pattern percentage result shows how often (%) a pattern appears.  
Example:  
If a pattern appears in 200 out of 400 analyzed draws, this results in a **50% appearance rate**.
